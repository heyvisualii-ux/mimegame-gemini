# MIME MASTER AI (مایم مستر) 🎭🎉

Next-generation AI-powered Persian Charades & Pantomime party game featuring MIMEO mascot, AI Game Master (powered by Google Gemini), dynamic difficulty, sound feedback, and interactive team battle modes.

## ✨ Features

- **MIMEO AI Mascot**: Interactive mascot that reacts to game events, gives motivational Persian commentary, and cheers for winners.
- **AI Game Master (Google Gemini)**:
  - Smart party analyzer that recommends game modes, timers, and rounds based on player count, group type, and mood.
  - Dynamic Persian word and scenario generator for any custom user topic.
  - Real-time commentary on streaks and combos.
- **6 Dynamic Game Modes**:
  - کلاسیک (Classic Pantomime)
  - چالش سرعت (Speed Challenge with combos)
  - نبرد تیم‌ها (Team Battle)
  - چالش هوش مصنوعی (AI Challenge)
  - خانوادگی (Family Friendly)
  - پارتی اکستریم (Party Extreme)
- **Interactive Gameplay**:
  - Hidden / Reveal Card mechanism
  - Animated SVG circular countdown timer ring
  - Built-in zero-dependency Web Audio API sound effects (correct chime, skip buzz, ticking, victory fanfare)
  - Persian hints system
- **Progression & Gamification**:
  - Leveling system, XP progress bar, coin rewards, daily streak.
  - Achievements gallery with unlockable badges.
  - Match history and statistics.
- **Community Words**:
  - User-submitted pantomime words and scenarios.
  - Real-time upvoting and trending list.
- **Persian RTL First**:
  - Native Right-to-Left design.
  - Vazirmatn and Lalezar typography.
  - Cohesive luxury midnight party aesthetic.

## 🚀 Running the App

```bash
# Install dependencies
npm install

# Start the development server (runs on http://0.0.0.0:3000)
npm run dev

# Build for production
npm run build
npm run start
```
