# PantoMix cPanel Shared Hosting Deployment Guide (Node.js Selector + Phusion Passenger)

This guide covers building, packaging, uploading, and verifying **PantoMix** (Next.js 15 standalone + `/api/ai/*` server routes) on cPanel shared hosting with **Node.js Selector** and **Phusion Passenger / LiteSpeed**.

---

## 1. Node.js Version & Compatibility

- **Supported Node.js versions:** **Node.js 20 LTS** or **Node.js 22 LTS** (`engines.node >= 20.0.0` in `package.json`).
- **Next.js Output Mode:** `output: "standalone"` in `next.config.ts`, with `images: { unoptimized: true }` (no native `sharp` binary required on shared hosting).
- **Passenger Startup Wrapper:** `app.js` at the application root.
  - Why not `.next/standalone/server.js`? Next.js's generated `server.js` hardcodes `parseInt(process.env.PORT, 10) || 3000` and `hostname = '0.0.0.0'`, which fails or binds conflicts when Phusion Passenger manages sockets (`typeof PhusionPassenger !== 'undefined'`) or when LiteSpeed `lsnode` passes a socket path in `PORT`.
  - `app.js` handles Passenger (`PhusionPassenger.configure({ autoInstall: false })` + `server.listen('passenger')`), numeric/socket `PORT` bindings without forcing `'0.0.0.0'`, `.env` loading, and Next.js production request handling.

## 3. Build & Package on Your Local Machine

Run these commands from the project root (on Windows PowerShell, macOS, or Linux with Node.js 20 or 22):

```bash
npm install
npm run typecheck
npm run cpanel:package
```

*(Note: `npm run cpanel:package` runs `NODE_ENV=production next build` and `node scripts/prepare-cpanel.mjs`, producing a self-contained **`deploy-cpanel/`** folder.)*

### Optional: Compress into a Single Archive Before Uploading
- **Windows PowerShell:**
  ```powershell
  Compress-Archive -Path deploy-cpanel\* -DestinationPath pantomix-cpanel.zip -Force
  ```
- **macOS / Linux:**
  ```bash
  cd deploy-cpanel && tar -czf ../pantomix-cpanel.tar.gz .
  ```

## 4. Exact Files & Directories to Upload to cPanel Application Root

Upload the **contents** of `deploy-cpanel/` (NOT `deploy-cpanel` as an extra parent folder) into your cPanel Application Root (for example `/home/<cpanel_user>/pantomix`):

- `app.js` *(Phusion Passenger startup entrypoint)*
- `package.json` *(runtime-only package manifest; excludes Capacitor/devDependencies)*
- `.next/` *(including `.next/BUILD_ID`, `.next/server/`, `.next/static/`, `.next/required-server-files.json`, etc.)*
- `public/` *(all images, fonts, icons, and `sw.js`)*
- `node_modules/` *(Next.js traced minimal production dependencies — avoids shared-hosting `npm install` OOM/timeouts)*
- `server.js` *(optional reference generated by Next standalone)*

**Do NOT upload:** `android/`, `src/`, `.next-dev/`, `mobile-shell/`, or `.git/`.

## 5. cPanel Node.js Selector Setup Steps

1. Log in to **cPanel → Software → Setup Node.js App** → **Create Application**.
2. Configure the fields:
   - **Node.js version:** `20.x` or `22.x` (e.g., `20.18.x` or `22.x`).
   - **Application mode:** `Production`.
   - **Application root:** `pantomix` (matches `/home/<cpanel_user>/pantomix`).
   - **Application URL:** `game.dresmaeiliclinic.ir` (path `/`).
   - **Application startup file:** **`app.js`**
3. Upload & extract `pantomix-cpanel.zip` (or `.tar.gz`) directly inside `/home/<cpanel_user>/pantomix`.
   - *Note:* Because `deploy-cpanel/node_modules/` is already bundled, you do **not** need to click "Run NPM Install" in cPanel (if cPanel created an empty `node_modules` symlink before you extracted the archive, delete that empty symlink first so `node_modules/` extracts cleanly).
4. In cPanel **Setup Node.js App → Environment Variables**, add:
   - `GEMINI_API_KEY` = `<your_real_gemini_api_key>`
   - `NODE_ENV` = `production`
5. Click **Save**, then **Restart** (or **Start App**).

## 6. Deployment Verification Checklist

1. **Homepage (`GET /`):**
   ```bash
   curl -i https://game.dresmaeiliclinic.ir/
   ```
   Expected: `HTTP/2 200` and Persian PantoMix HTML (`<title>PantoMix | پانتومیکس</title>`).
2. **Static Asset Check (`/_next/static/` & `public/`):**
   ```bash
   curl -I https://game.dresmaeiliclinic.ir/pantomix_mascot.jpg
   ```
   Expected: `HTTP/2 200` (`image/jpeg`).
3. **AI Reaction Endpoint (`/api/ai/reaction`):**
   ```bash
   curl -sS -w "\nHTTP:%{http_code}\n" -X POST https://game.dresmaeiliclinic.ir/api/ai/reaction \
     -H "Content-Type: application/json" \
     -d '{"isSuccess":true,"score":20,"combo":2}'
   ```
   Expected: `HTTP:200` and `{"success":true,"reaction":"..."}`.
4. **AI Words Endpoint (`/api/ai/words`):**
   ```bash
   curl -sS -w "\nHTTP:%{http_code}\n" -X POST https://game.dresmaeiliclinic.ir/api/ai/words \
     -H "Content-Type: application/json" \
     -d '{"topic":"سینما","count":3,"difficulty":"MEDIUM"}'
   ```
   Expected: `HTTP:200` and `{"success":true,"data":[...]}`.
5. **AI Recommendation Endpoint (`/api/ai/recommend`):**
   ```bash
   curl -sS -w "\nHTTP:%{http_code}\n" -X POST https://game.dresmaeiliclinic.ir/api/ai/recommend \

     -d '{"playerCount":4,"groupType":"FRIENDS","mood":"FUNNY","minutes":30}'
   ```

   Expected: `HTTP:200` and `{"success":true,"data":{...}}`.
6. **Secret Safety Check:** Confirm `GEMINI_API_KEY` does not appear anywhere in browser DevTools → Network/Sources.
7. **Firebase Auth Check:** Sign in with Google on `https://game.dresmaeiliclinic.ir/` (confirm `game.dresmaeiliclinic.ir` is in Firebase Authorized Domains).
